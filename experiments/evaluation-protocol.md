# Stage 6 protocol (declared before the main run)

Evaluate the existing selected imitation-v1 forest, Teacher 2.0.0 with 128 samples and existing RuleBot budgets. No training, selection or data split changes. PokerKit/Game retains 2000 chips per seat, blinds 10/20, no rake and the moving button.

Main configuration: evaluation-v1.json; 12 common seed blocks for A/B/C, four cyclic rotations of each complete roster, 100 settled hands maximum. D uses the first eight blocks and all four rotations. Pilot uses a separate block and eight hands, excluded from strength results. A: learned + rule styles 0/1/2. B: teacher + same rules. C: marked style-0 rule + same rules. D: learned + teacher + rules 1/2. The target is roster index 0. D's teacher follows it clockwise. Styles remain attached to identities, not physical seats. C is a specific conservative baseline, not an average over all rule styles.

Each hand's deck permutation comes from SHA-256('deck|block|hand'), first eight bytes as a big-endian integer passed to random.Random. Teacher's separate stream uses SHA-256('agent|block|rotation|identity'). Neither stream/seed is passed to policies. All decisions use views.observe. Shared deck permutations do NOT guarantee identical cards to a named agent after different eliminations, dealing order, street reach, or relative seat mappings. Pairing is at seed-block level, not identical counterfactual hands. The initial dealer is always Game's original seat 3, advancing to seat 0 on hand 1.

Primary outcome: target end chips minus 2000 after regular tournament completion or 100 settled hands. Target may bust earlier; sessions continue with remaining players. Errors are reported separately and excluded from strength means; no error session is silently retried/replaced. Record last settled bankroll, action/error counts and incomplete-hand indicator on failure. A capped bankroll is not a tournament win. Conditional win fraction uses only fully completed tournaments and is subject to duration/selection bias.

Report means, medians, sample session SD, ranges, eliminations, outcome counts, seat-specific results, actions, and all-ins. Primary uncertainty: percentile 95% bootstrap intervals from 10000 resamples of independent seed blocks; all four rotations retained together and equally weighted. Paired A-B, A-C and B-C contrasts resample the same common blocks. D learned-teacher contrast is paired within each complete block. Only complete non-error four-rotation blocks enter these intervals. No hand-level independence assumption. Seat comparisons, action proportions and all-in counts are descriptive/exploratory, without multiplicity-adjusted inference.

Common action categories: fold, check, paid call, raise (includes bets). All-in action means submitting the remaining stack via call/raise, even if excess is later refunded; it is an annotation overlapping call/raise, not a separate exclusive action category. Also count blind all-ins, unique all-in hands, and decisions facing an active opponent with zero stack. Canonical learned/teacher labels are recorded separately: clipped small/large and call can also be all-ins. No interpretation of normalized tournament chips as a cashgame winrate.

Checkpoints are atomic, keyed by scenario/block/rotation, source/config/model/data fingerprinted. Resume skips all existing sessions, including errors. Merge deduplicates identical semantic records, rejects conflicts and mismatched fingerprints. At most four processes; model n_jobs remains 2. Reporting and bootstrap do not feed back into agents or the selected artifact.
